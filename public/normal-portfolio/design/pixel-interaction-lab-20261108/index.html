Preparing a task replaces the board. Changing the input condition keeps your drawing. Use the same prepared task for each condition.

28 × 18 board

Arrow keys move between squares. Enter or Space activates a square. Home/End move along a row; Ctrl+Home/End reach the board’s corners. Ctrl+Z undoes an action. On a narrow screen, use Move board view to pan without painting.

Undo restores the last action, including Reset. A drag stroke counts as one action. The last 100 actions are available in every condition. Cream is the clearing colour.
